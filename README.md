### 新手手册

请查看[新手手册](./新手手册.md)。游戏内主菜单按 `3` 可打开分
页操作说明；在手册页按 `D` 可打开下载页，按方向键翻页。
游戏会将语言、界面缩放比例和单人行动进度保存在 `%APPDATA%\mokthyn\save.dat`。
主菜单按 `7` 打开设置，可按左右方向键将界面按 100%–130% 等比例放大，窗口尺寸保持不变；按 `0` 恢复默认比例。

### 简介

这是个逃离雅科夫模式的游戏，搜、打、撤功能。
